# Liar's Hand

A neon-soaked multiplayer bluffing card game. Lie to your friends, call their bluffs, and clear your hand to win.

## Development

```bash
npm install
npm run dev
```

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Supabase (realtime multiplayer)
- Framer Motion (animations)
- shadcn/ui components
